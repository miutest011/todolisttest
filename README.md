# 我的待办清单

一个纯前端的待办清单，可以装到手机主屏幕上当 App 用。没有用任何框架和构建工具，
所有数据都存在你自己的设备里，不上传到任何服务器。

## 文件结构

```
index.html      页面骨架
style.css       样式
app.js          待办清单的逻辑（清单、今天、详情页、提醒、附件……）
tags.js         标签界面（顶部标签行、长按管理），清单页和打卡页共用
logs.js         打卡功能（和待办是两块独立的数据）
manifest.json   PWA 配置（应用名、图标、启动方式）
sw.js           Service Worker，负责离线缓存
icons/          应用图标
tools/          测试工具（见 tools/README.md）
```

## 在电脑上打开

直接双击 `index.html` 就能用。

想测试 PWA 相关功能（安装、离线）的话，必须通过服务器打开：

```bash
python3 tools/dev-server.py
```

然后访问 http://localhost:4173

> 用这个脚本而不是 `python3 -m http.server`，因为它会明确告诉浏览器**不要缓存文件**。
> 用自带的那个服务器，你改完代码刷新页面看到的常常还是旧版本，很容易误以为是代码写错了。

## 装到 iPhone 上

**前提：必须是 https 网址。** 手机直接访问 `http://192.168.x.x:4173` 这种局域网地址
是不行的——浏览器只在 https 或 localhost 下才允许 Service Worker 运行，
装不成 App、也不能离线。

### 用 GitHub Pages 发布（免费）

1. 在 [github.com/new](https://github.com/new) 建一个仓库（**Public**，GitHub Pages 免费版需要公开仓库）

2. 把代码推上去（把 `你的用户名` 和 `仓库名` 换成实际的）：

```bash
git remote add origin https://github.com/你的用户名/仓库名.git
```

```bash
git push -u origin main
```

3. 在仓库页面点 **Settings → Pages**，Source 选 `Deploy from a branch`，
   分支选 `main`、目录选 `/ (root)`，保存

4. 等一两分钟，网址会是 `https://你的用户名.github.io/仓库名/`

### 添加到主屏幕

在 iPhone 上**用 Safari**打开那个网址（Chrome 不行，iOS 只有 Safari 支持添加 PWA）：

分享按钮 → 添加到主屏幕 → 添加

装好后就有自己的图标，点开是全屏的，没有 Safari 的地址栏。

## 三个标签页

底部有三个标签：

- **清单**：按清单分组管理所有任务（原来的主界面）
- **今天**：把所有清单里**今天到期**和**已经过期**的任务汇总到一页，过期的单独标红排在前面
- **打卡**：记录"做了几次"的事，比如喝水、健身、给猫驱虫

"今天"页只显示设了截止时间的任务。没设截止时间的任务不会出现在这里——
想让某条任务出现在"今天"，进它的详情页点时钟图标设个时间。

## 操作方式

| 想做什么 | 怎么做 |
|---|---|
| 看任务详情 | 点这一行任意位置。详情页标题下面是它所在的清单（虚线框）和闹钟；状态看勾选框，开始时间不显示（数据里还记着） |
| 标记完成 | 点左边的方框 |
| 改任务名 | 详情页里点标题，或 ⋯ 菜单 → 重命名 |
| 展开 / 收起清单 | 点清单标题栏任意位置。**一次只展开一个**：点开一个，其它的自动收起 |
| 新建任务 | 点右下角蓝色的 **+**，填名字、点选放进哪个清单（蓝底的是选中的，默认是展开着的那个）；这一排最后的**闹钟**可以顺手设截止时间和提醒，和详情页里的一样。**按键盘上的回车**加完面板还开着，接着输下一条；空着回车或点"添加"就收起 |
| 改清单名 | 清单的 ⋯ 菜单 → 重命名 |
| 排序 / 换清单 | **手机上按住不放约半秒**再拖；电脑上按住鼠标直接拖。拖到**收起来的清单**上松手，就放进那个清单的最前面 |
| 置顶 | 在清单页点任务右边的 ↑ 箭头（"今天"页和详情页上没有，免得分不清是在哪置顶） |
| 设截止时间和提醒 | 详情页标题下面、清单标签旁边的**闹钟**。没设时是灰色小闹钟；设了时间闹钟变红，旁边写"今天 22:50""明天 09:00"这样的时间 |
| 放弃某条 | ⋯ 菜单 → 放弃这条 |
| 重新捡起放弃的 | 展开"已放弃"分组 → ⋯ 菜单 → 重新拾起 |
| 按类别看清单 | 点顶部的标签；标签多了可以横着滑 |
| 新建标签 / 改名 / 删除 | 顶部"+ 新增"；**手机上长按**标签（电脑上右键）出现"改名 / 删除" |
| 把清单放进某个标签 | 清单的 ⋯ 菜单 → "放到标签"下面点一个；停在某个标签下新建的清单会自动放进去 |
| 暂时不用的清单 | 清单的 ⋯ 菜单 → 归档；想恢复就去"已归档"里 → ⋯ 菜单 → 取消归档 |
| 新建清单 | 点标签行最右边的 **⋯** → 新建清单，填名字、顺手选放进哪个标签（默认是当前正在看的标签） |

**清单的标签像文件夹**：一个清单只能放在一个标签下，放进别的标签就从原来那个拿出来。
和打卡页的标签是两套，互不影响。

- **所有**：所有没归档的清单
- **已归档**：归档时拿掉它的标签；**里面的任务不会出现在"今天"页，也不会提醒**，任务的"移动到"里也不列它。取消归档后一切恢复（标签要重新放）
- 删除标签**不会删掉清单和任务**，只是这些清单不在任何标签下了
- 每次打开 App 都从"所有"开始

**任务有三种状态**：

- **未完成**：空方框，直接列在清单里，置顶的排最上面
- **已完成**：灰色的勾 ✓，收进"已完成"折叠分组
- **已放弃**：灰色的叉 ✕，收进"已放弃"折叠分组

放弃和删除的区别：**放弃不会丢掉这条记录**，还能看到自己曾经尝试过，
哪天想重新捡起来也还在。删除才是真的没了。

已完成和已放弃的分组每次打开都是收起的——它们本来就是为了让清单看起来短。

**右下角的 + 按钮**一直浮在那里：清单页上是"新建任务"，打卡页上是"新增打卡"。
新建清单一年也用不了几次，所以放在标签行右边的 ⋯ 里，不占这个最显眼的位置。
"已归档"和详情页上没有 +；"今天"页暂时也没有；一个能放任务的清单都没有时，清单页也不显示。
点开的新建面板在屏幕**上方**，是故意的：iPhone 上弹键盘时，贴在底部的东西常被键盘挡住。

**打字的时候，底部标签栏和 + 按钮会先藏起来**，光标离开就回来。
iPhone 弹键盘时会把贴底的东西一起顶到键盘上面，挡住正在输入的地方。电脑上没有弹出键盘，所以不藏。

**一次只展开一个清单**，展开记录会保存，下次打开还是它。一条任务都没有的清单，展开时下面会有一行小字"该清单内还没有内容，点击添加"，点它和点右下角 + 一样（已归档的清单只写"还没有内容"，不能再往里加）。清单底下不再有"+ 添加任务"，新建任务一律用右下角的 +。

**清单页、今天页、打卡页的顶部都是固定的**：往下滚的时候，标签行（今天页、打卡页连同标题）停在上面不动，只有下面的内容在滚，也不显示滚动条。
点面板外面的暗色区域、按"取消"都能关掉。

**页面不会被放大**：输入框的字都是 16px（再小 iPhone 一点进去就自动放大、而且缩不回去），
连点两下也不会放大（打卡时连点数字很容易触发），页面设置里也禁止了双指缩放。
双指缩放那一条苹果不一定听——Safari 为了照顾视力不好的用户会无视这个设置，所以另外加了一段专门拦 iPhone 手势的代码。

改名之所以只放在详情页和菜单里，是因为手机上任务文字占了一行的大半面积，
如果点文字是改名，那么想进详情页几乎必然误触。一行里只放一个主要动作。

### 打卡

| 想做什么 | 怎么做 |
|---|---|
| 新增打卡项目 | 点右下角蓝色的 **+**，填名字、顺手选标签 |
| 记一次 | 点右边的大数字 |
| 点错了 | 马上点底部弹出的"撤销"（几秒后自动消失） |
| 事后发现有一次记错了 | 进详情页，点那天的日期，在下面的记录里删掉那一条 |
| 忘记打卡、事后想补上 | 进详情页，点那天的日期，下面会出现"+ 补录一次" |
| 看某天打了几次 | 进详情页，点月历上的那一天，下面就列出那天的每一次 |
| 看每个月打卡情况 | 详情页的月历左右翻月份 |
| 改名 / 删除项目 | 详情页的 ⋯ 菜单（删除会连带所有打卡记录，会先问你） |
| 按类别看 | 点顶部的标签；标签多了可以横着滑 |
| 新建标签 | 顶部最右边"+ 新增"；新增打卡时、详情页里也有"+ 新增标签" |
| 给项目加 / 去标签 | 新增打卡时点选；以后改就进详情页，点标题下面的标签 |
| 改标签名 / 删标签 | **手机上长按**顶部的标签（电脑上右键），下面会出现"改名 / 删除" |
| 不再打卡但想留着记录 | 详情页 ⋯ 菜单 → 归档；想恢复就去"已归档"里找到它 → ⋯ 菜单 → 取消归档 |

列表上的大数字是**累计总次数**。

**标签**：顶部一行是 `所有 | 你自己建的标签… | 已归档 | + 新增`。一个项目可以有好几个标签。

- **所有**：所有没归档的项目
- **已归档**：归档了的项目。归档时会**去掉它身上所有的标签**，取消归档后标签不会自己回来，要用再加
- 删除标签**不会删掉项目和记录**，只是这些项目身上少了这个标签
- 停在某个标签下点"+ 新增打卡"，会默认带上这个标签
- 每次打开 App 都从"所有"开始

详情页从上到下是：横排三个小方块（总次数 / 本月 / 上次打卡）、月历、选中那天的记录。
月历上**打过卡的日子会用手写风格的黑色圈圈出来**，今天是灰底圆，选中的那天是蓝底圆。
月历只回答"这天打没打"，打了几次看下面的记录列表——刚进详情页时默认看今天，
翻到别的月份时默认选中那个月 1 号。

如果选中的是**已经过去、又没打过卡**的日子，记录列表下面会出现"+ 补录一次"：
填个时间点"确定"就补上，补上的记录和平常打的完全一样，也能再删掉。
今天不显示这个入口（直接点大数字更快），还没到的日子也不显示。

## 想调整外观

**所有颜色、字号、间距、圆角都集中在 `style.css` 开头的 `:root` 那一块**，
下面的样式里不再出现具体数值。想整体换个风格，改这一块就够了，不用满文件找。

比如换主色调，只要改一行：

```css
--accent: #4a90e2;   /* 改成 #e8734a 就整体变成橙色系 */
```

几条约定：

- **间距只用 4 的倍数**（`--space-1` 到 `--space-7`），别写 7px、13px 这种随手来的数
- **字号只有 6 档**，别每处都不一样
- **灰色只有 5 档**（标题 / 正文 / 次要 / 说明 / 极淡），够用了

界面"看起来没设计感"，往往不是因为缺什么炫技效果，而是这些细节不成体系——
之前这个文件里散落着 23 个颜色，其中一半是肉眼分不出的灰。

**图标**用 SVG 画，路径存在 `app.js` 的 `ICON_PATHS` 里。想换图标，
去 [Lucide](https://lucide.dev)、[Feather](https://feathericons.com) 或
[Heroicons](https://heroicons.com) 复制一段 `d="..."` 贴进去就行——
它们都是免费可商用，画法规格（24×24、圆头圆角、只描边）和这里一致。

## 改了代码之后

**记得把 `sw.js` 里的版本号加一**：

```js
const VERSION = 'v6';   // 改成 'v7'、'v8'……
```

不改的话，手机上会一直用缓存里的旧版本，你的修改不会生效。

**新增了脚本文件的话，还要把它加进 `sw.js` 的 `FILES` 列表**，否则装成 App 离线打开时会缺这个文件。
这一条有测试盯着：`index.html` 里加载了、但缓存列表里没有的脚本，测试会直接报红。

改完推上去，手机上把 App 关掉重开一次就是新版本了。

## 已知的限制

- **数据不同步**。数据存在各设备的浏览器里，手机上加的任务电脑上看不到，反之亦然。
  想同步需要服务器和账号系统，那是后面的事。

- **关掉 App 就不会提醒**。提醒是靠网页里的定时器实现的，App 关掉后定时器就停了。
  iOS 上网页只能收服务器推送的通知，没法自己定本地闹钟。想要真正的后台提醒，
  需要用 Capacitor 之类的工具打包成原生 App。

- **别在浏览器里清除网站数据**，那样待办、打卡记录和附件都会没了。

- 附件存在浏览器的本地数据库里，容量取决于设备剩余空间，视频塞太多可能会存不下
  （存不下时会有提示）。

## 测试

改完代码打开 `tools/test.html` 看一眼，全绿就说明没改坏东西。

想确认测试本身靠不靠谱，打开 `tools/mutate.html`：它会把代码一处处故意改坏，看测试能不能发现。详见 [tools/README.md](tools/README.md)。
